# Changelog

All notable changes to `incidentiq-sdk-golang` are documented in this file.

The format is based on Keep a Changelog and this project follows Semantic
Versioning. Per-release notes for published tags are generated on the
[GitHub Releases](https://github.com/herooftimeandspace/incidentiq-sdk-golang/releases)
page; this file records the changes that shape the public Go surface.

## [Unreleased]

### Changed
- Documentation is no longer synced from the `incident-py-q` source SDK. The
  README, contributor docs, and project docs describe the Go API, the Go
  toolchain, and this repository's own CI instead of a Python package.
- `docs/sdk-reference/` is now generated by `scripts/generate_sdk_reference.go`
  from the bundled contract artifacts, in Go terms: `client.<Namespace>.<Method>`
  accessors, the shared `(ctx, RequestOptions, out)` signature, and a
  `RequestOptions` field per documented parameter. It replaces the copied Python
  reference pages, which documented sync/async methods, `.raw(...)` calls, and
  `Python Arg` parameter tables that this SDK does not have.
- `scripts/sync_from_source_sdk.sh` copies machine-readable contract artifacts
  only. It no longer overwrites Markdown, so Go-specific documentation survives
  a sync.
- `go generate ./...` now runs both generators, and `generated_wrappers.go` and
  `docs/sdk-reference/` must be committed together.

### Added
- `TestGeneratedReferenceMatchesWrappers` fails when the generated reference and
  the generated wrappers disagree about the method surface.
- `TestGeneratedReferenceIsGoShaped` fails if the reference pages reintroduce
  the source SDK's Python call shape.
- `data/typed_silver_methods.json` now records the route, signature, and summary
  of each hand-written typed Silver helper, so the reference documents them
  beside the generated wrappers.

## [0.1.0] - 2026-06-29

### Added
- Initial `incidentiq` Go module with a single `*Client` and a
  `context.Context`-aware request path.
- Bearer-token auth by default, with optional raw mode, the optional `SiteId`
  header, and configurable app headers.
- Tenant base URL normalization, HTTPS-only validation, and tenant-root handling
  for `/api/`, `/services/`, `/apps/`, `/img/`, `/s/`, and `/pub/`.
- Retries for idempotent methods on retryable statuses, with exponential backoff
  and a bounded response body.
- Generated wrappers for the bundled Golden and Silver inventories: Golden on
  `client.<Namespace>.<Method>`, Silver on `client.Silver.<Namespace>.<Method>`,
  and app routes on `client.Silver.Apps.<AppNamespace>.<Method>`.
- Deprecated forwarders for every pre-migration Golden method name, plus
  `LegacyAliasConflicts()` for the one name that changed meaning.
- Typed Silver helpers for the user room-association routes.
- Embedded contract artifacts with accessors (`GoldenInventory`,
  `SilverInventory`, `OpenAPIContractMetadata`, `LegacyAliases`).
- Static docs site tooling and GitHub Actions workflows for quality gates,
  integration tests, promotion, docs publishing, and releases.
